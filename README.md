# Today for Android

Last ned den signerte appen under [Releases](https://github.com/oyvhov/today-app-releases/releases/latest).

Dette er berre nedlastingskanalen. Kjeldekode, kontonoklar og feilsokingskart blir ikkje publiserte her. Appen inneheld dei eksisterande profilbileta, med eigaren sitt samtykke.

Installer den forste utgava via APK-lenkja. Seinare oppdateringar finst under Oppsett -> Tenester -> Appoppdateringar. Android ber deg godkjenne installasjonen.
